## How to start a multiplayer session

Choose a host with a stable connection, update every copy of the game, and complete the platform's online setup. Join the active friend game when it appears, or use the host's Join Code from the host menu or Session Details. Start with a short test session so the group can confirm voice or text communication and invite visibility.

## Co-op puzzle coordination

Give each player a role: navigator, clue reader, interaction tester, or map marker. Say the landmark and objective before moving so nobody activates a puzzle while another player is still collecting the clue.

## Cross-platform groups

Big Walk supports crossplay across Windows, macOS, PS5, and Switch 2. Use the [crossplay guide](/crossplay/is-big-walk-cross-platform) to check the current setup before scheduling a session.

## Invite troubleshooting

- Confirm the host's privacy and party settings.
- Check that every player is on the same version.
- Restart the game after a platform update.
- Re-check account linking and online access.
- Try a fresh host if the invite remains invisible.
