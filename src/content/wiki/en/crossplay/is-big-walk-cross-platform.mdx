## Does Big Walk support crossplay?

Yes. Big Walk's official FAQ confirms that players on different systems can play together. The current release supports Windows, macOS, PlayStation 5, and Nintendo Switch 2, with crossplay between them.

## Can PC play with PS5?

PC and PS5 players can play together. Confirm both copies are updated, then use the active friend game or the host's Join Code if the session does not appear. See the [Big Walk PS5 guide](/platforms/ps5) and [multiplayer guide](/multiplayer/big-walk-multiplayer) for setup steps.

## Does Switch 2 support multiplayer?

Switch 2 is one of the official release platforms and supports crossplay with the other current systems. Nintendo Switch Online and the game's current version are still required for online play. The [platform comparison](/platforms) is the quickest reference for the full list.

## How crossplay multiplayer works

1. Update every copy of Big Walk to the same version.
2. Start a session and check the active friend-game list.
3. If the session is hidden, share the host's short Join Code.
4. If a friend cannot join, compare platform, privacy settings, online access, and game version.

For group planning, keep the [Big Walk multiplayer guide](/multiplayer/big-walk-multiplayer) open alongside this page.

## Crossplay troubleshooting checklist

- Confirm both players have online access enabled.
- Restart the game after an update so version checks refresh.
- Check that the host's privacy setting allows friends to join.
- Use the same server or region when the game exposes that option.
- Re-check official patch notes if a platform update has just released.
